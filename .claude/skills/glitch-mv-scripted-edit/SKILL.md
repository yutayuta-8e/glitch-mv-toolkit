# glitch-mv-scripted-edit

生成素材と曲から、カオス系 MV を「台本（スクリプト）だけで」作って直していく手順。実例は「ゆた×目／見てるよ」（2026-11-06〜07、101〜106 秒、1920×816、24fps）。このリポジトリの `docs/HOWTO-glitch-mv.md` に全体の手順と値をまとめてある。スクリプトはリポジトリ直下の `video/`・`audio/`・`thumbnail/`・`tools/`・`examples/`。

## 進め方

1. **素材をそろえる**：カットを1ファイルずつに分ける。黒背景のオーバーレイは黒を透過した ProRes 4444 にする。曲は公式ダウンロードした WAV を `音源/` に置く。→ `references/production-flow.md`
2. **映像**：カオス編集（区間ごとのカット長・効果数）→ 文字の層 → 終盤スパートの文字の層 → 注意書き → 仕上げ。→ `references/video-edit.md`
3. **音**：Suno 曲を土台に、合成のブレイクコア／ピアノ／ラストの壊し／セリフ／余韻を重ねる。→ `references/audio-edit.md`
4. **確認はプレビューで**：1280 幅・速い設定で 4 分前後。本人が OK を出してから、本番（1920×816・CRF18 slow、8 分前後）を書き出す。
5. **サムネ**：MJ（人物なし）→ 動画と同じ仕上げで 10 通り加工 → 番号で組み合わせ。→ `references/thumbnail.md`
6. 版ごとに、何を変えたか・どこに出したか・何を確かめたかを作品の記録ファイルに残す。

## 守ること

- 元ファイル・前の版は上書きしない。版を上げて別名で出す（v5 → v6 → v7、`_preview` / `_final` / `_phone`）。
- 有料生成（TapNow の MJ・H3、Suno の生成）は依頼された分だけにする。クレジット消費は報告し、MCP で見られなければ「未確認」と書く。
- 商用条件は作品ごとの権利の台帳で管理する（台帳はこのリポジトリには入れていない。作例の要点は README の「権利」）。フォントはいいフォントの OFL 書体を使う。Salamander Grand Piano V3 は CC BY 3.0 なのでクレジット表記が要る。Suno は有料プランでの生成と公式ダウンロードが条件。
- 見ていない・聴いていないことは「未確認」と書く。AI は音を聴けないので、音量の推移・スペクトログラム・コマ一覧の実測で確かめる。
- 一時ファイル（カットごとの mp4、透明 MOV）は作業用の一時フォルダに置き、成果物は作品ごとの出力フォルダに置く。

## つまずきやすい点（詳細は `references/pitfalls.md`）

- ffmpeg drawtext の縁取り（borderw）は、中を透明にしても縁の色で塗りつぶされる。線だけの文字は PIL で輪郭の PNG を作り、overlay で重ねる。
- drawtext は改行を□（豆腐）として描く。縦書きは1文字ずつ描いて縦に積む。
- 字が無いのを四角い字形で描くフォント（激筆SFX）があり、豆腐チェックをすり抜ける。怪文書は1文字ずつ四角い紙に入った字形、クロヌリは字が黒い棒なので、どちらも四角い枠に見える。依頼者は「四角い枠はいらない」。
- 歪みを足すと、音の山と山の間（トゥルーピーク）が 0 dB を超えやすい。サンプルのピークを -3 dBFS にそろえる。

## スクリプト（リポジトリ直下、すべて `python -I` で動く）

| 場所 | 中身 |
|---|---|
| `video/chaos_edit_v3.py`（前の版 `chaos_edit_v2.py`） | カットを区間ごとの長さ・効果数で並べ、二重露光・透過オーバーレイ・色フラッシュ・一瞬の文字を足す（plan.json と seg*.mp4）。`--plan` で並びを固定、`--scale 2` で 4K |
| `video/chaos_text_v5.py`（前の版 `chaos_text_v4.py`） | 各カットに文字を足す。線だけのアウトライン（6px）、縦書き、スパート前は控えめ。`--preview` / `--segments-only` / `--scale` |
| `video/spurt_layer_v2.py` + `video/fable_render/` | 終盤スパートの文字の層（透明 MOV）。62.4〜92 秒で文字を増やし、最後は画面を埋める。3 つ目の引数が倍率 |
| `video/black_to_alpha.py` | 黒背景の動画を、黒が透明な ProRes 4444 にする |
| `video/warn_4k.py` | 採用した注意書き（にじみ明朝、静止）を倍率付きで描く |
| `video/warning_designs.py`、`warning06_v2.py`、`bleed_*.py`、`outline_variants.py` | 注意書き 10 案、採用案の改訂、にじみ加工の比較、アウトラインの太さの比較 |
| `audio/remix_audio.py`、`breakcore_audio.py`、`breakcore_v2.py` | Suno 曲 + 合成の楽器 → ブレイクコア → ピアノ・加速・ドラム追加・壊し・セリフ・余韻 |
| `audio/sfz_piano.py`、`musio_piano.py`、`piano_ideas.py` | Salamander（SFZ）を演奏データどおりに鳴らす、演奏データ、ピアノ 5 案 |
| `thumbnail/thumb_fx.py`、`thumb_fx_combo.py` | サムネの 10 通りの加工と、組み合わせ版（書体の場所は環境変数 GLITCH_MV_FONTS） |
| `examples/build_example.sh` | 素材 → カット → 文字 → スパート → 組み立てまでの流れの例（上のパスを書き換えて使う） |
| `tools/*` | 確認用の小道具（コマ一覧、音量の推移、版の比較、セリフ探し、X 向けの書き出し） |

スクリプトの冒頭の docstring に、使い方と、その版で何を変えたかを書いてある。曲の区間（秒）は「見てるよ」に合わせた値なので、別の曲では `SECTIONS` / `PLAN` / `RAMP_A, RAMP_B` などを曲の構成に合わせて直す。
