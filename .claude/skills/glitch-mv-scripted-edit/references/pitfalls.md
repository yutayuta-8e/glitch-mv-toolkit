# つまずいた点と直し方

読むタイミング：ffmpeg の文字・フォント・シェル・音量で詰まったとき。作る前にも一度目を通す。

## 文字とフォント

- **drawtext の縁取りは塗りになる**：`borderw` は文字を太らせた形を縁の色で塗る。`fontcolor=...@0` にしても中まで埋まる。v3〜v5 の「アウトライン」は実は全部塗りだった。線だけにするなら、PIL で輪郭の PNG を作って overlay で重ねる（`chaos_text_v4.py`）。PIL の `stroke_width` で描いてから元の字を引く方法でも抜ける（Fable 版 `text_layer`）。
- **drawtext は改行を□で描く**：`\n` が「字が無い」記号（×の入った四角）になる。CRLF のせいではない。縦書きは1文字ずつ描く。
- **豆腐チェックをすり抜けるフォント**：激筆SFX は、無い漢字を全部同じ四角の字形で描く。U+E000 との比較だけでは見抜けない。めったに使わない漢字 2 つを描いて形が同じなら、それを無い字の形とみなす。
- **四角い枠に見えるフォント**：怪文書は1文字ずつ四角い紙に入った字形、クロヌリは字が黒い棒。線だけにすると四角い枠になる。依頼者は「要らない」と言ったので、怪文書は外し、クロヌリは塗りだけで使う。
- **drawtext の文字列の記号**：コロンはフィルタを壊す（`SYSTEM ALERT:` → `/` に置き換えた）。▶・⚠ は多くのフォントに無い。
- **中央揃えのずれ**：全角の句読点があると、文字の箱で中央にしても左右にずれる。描いてから `getbbox` でインクの外枠を測ってそろえる。
- **文字の大きさ**：縦書きは列が画面に収まる大きさに縮める。スパート前は小さく・少なく・アウトライン多め（依頼者「主張が強い」）。

## ffmpeg とシェル

- enable の式の中のカンマは、シングルクォートで囲めばそのまま書ける（バックスラッシュを付けると壊れる）。位置の式（`mod(n*40\,w+tw)`）はクォートの外なので `\,` が要る。
- overlay の位置の式は `W,H`（画面）と `w,h`（重ねる画像）。drawtext の `w,h,tw,th` とは逆になる。
- 1 枚の PNG を overlay すると、最後のコマが出続ける（eof_action の既定 repeat）。
- heredoc を `&& \` でつなぐと、バックグラウンドの処理が壊れる。手順を分けるか、スクリプトのファイルにする。
- `rm -rf "$d"` は安全チェックで止められる。`"${d:?}"` で空のパスを防ぐ。
- `python -I` は、スクリプトのフォルダからの import を無効にする。部品を import するスクリプトは `sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))` を入れる。
- 文字ファイルは `newline="\n"` で書く。

## 音

- ドラムの小節の長さを 2 倍にしてしまったことがある。1 小節 = `2*60/bpm`（曲の 2 拍）。
- 合成ピアノはそのままだと遅い。音ごとの結果をキャッシュする（音・長さ・強さを丸めた鍵）。
- 重ねて割れた：リミッター -3dB ＋ サンプルのピークを決めた値にそろえる。歪みを足した版ではトゥルーピークが +0.9〜+1.8 dBTP になったので、ピークを -3 dBFS にした（-0.4 dBTP）。
- SFZ はリリースとペダルの group を読み飛ばす。
- 外のピアノ WAV は曲の長さで切れる。余韻を延ばすときは、音を引き延ばしてから残響で消す（ただ残響を足すだけだと、急に落ちる）。
