# 全体の流れ（ゆた×目／見てるよ の実例）

読むタイミング：新しいカオス系 MV を始めるとき、どの順で何を作るか決めるとき。

## 1. 世界観と素材（生成）

1. MJ で雰囲気の絵を作る。TapNow 公式 MCP の `midjourney-v8.2` を使い、依頼者指定の sref をプロンプトの末尾に付ける（例 `--sref 2207025010 2974221769 4044751972`）。
   - プロンプト内の `--ar 21:9` は、MCP の比率指定より優先される。
   - sref が強く効いて、パステルピンクの手描き調に寄る。暗くしたいなら sref を外すか弱める。
2. 依頼者が採用した絵を世界観の参照にして、H3（`minimax-h3`、reference、21:9、2k、15 秒）で 15 秒のクリップを作る。書き方は h3-prompt-writing。
   - セリフ（ささやき）は `<d>[Japanese] みてるよ。</d>` のように入れる。あとで音の素材として切り出せる。
3. 人物の写っていないオーバーレイ用のクリップ（動き派手、黒背景）も作る。

## 2. 素材の下ごしらえ

- **カット分割**：ffmpeg のシーン検出（`select='gt(scene,0.3)',showinfo` で切り替わりの時刻を出す。H3 の 15 秒は 9 回＝10 カット前後）で、1カット1ファイルにする。Filmora で参照する用に、全カットを1ファイルにまとめた版も作る。
- **黒の透過**：`video/black_to_alpha.py <src> <out.mov> --lo 10 --hi 48`。RGB の最大値からアルファを作り、ProRes 4444 で書き出す。重いのは許容（依頼者「重くてもいいよ」）。
- **曲**：Suno の公式 Download（WAV）。Pro プランかどうかを `LICENSES.md` に記録する。ログインは依頼者が Chrome で行う。

## 3. 編集の版の上げ方（依頼者の指示と、その反映）

| 版 | 依頼者の指示 | 反映 |
|---|---|---|
| v1〜v2 | 「めちゃくちゃに、フィルターとかエフェクトもガッツリ」「フラッシュワーニングつけちゃう」 | `chaos_edit_v2.py`：区間ごとのカット長・効果数、二重露光、色フラッシュ、注意書き |
| v3 | 「文字もっと、大胆に大きく、アウトラインだけとか、フォント色々（いいフォントで）、わけわかんない言葉」 | `chaos_text_v3.py`：いいフォント 14 書体、言葉の候補、塗りとアウトライン、巨大、流れる、点滅 |
| v4 | 「注意書きは 6 番」「本文は明朝体、にじみ多め、中央揃え」「Fable の文字ぐちゃぐちゃを終盤スパートだけ採用、最後は画面一面」 | 注意書き 7 秒・インクの外枠で中央、`spurt_layer.py` |
| v5 | 「スパート前は文字の主張が強い」「DnB 充実」「注意書きのカメラの動きは要らない」「もっとにじむ明朝」 | スパート前を控えめに、`--more-drums`、注意書きを静止、幻ノにじみ明朝＋にじみ加工 2-B |
| v6 | 「アウトラインは塗りなしの線だけ（太さは見本 3＝6px）」「ラストに向けて DnB をめちゃくちゃに」「『見てるよ』のセリフを入れて」「レンダリング短くして見せて、確定したら高品質」 | `chaos_text_v4.py`、`--wreck`、`--voice`、プレビュー／本番の二段構え |
| v7 | 「フォントの周りの四角い枠は要らない」「最後の余韻を今の 2 倍以上」 | 怪文書を外す、クロヌリは塗りだけ、豆腐チェック強化、`--tail-extend 4.5` と黒の延長 |

決め方の型：案を N 個並べた静止画（コンタクトシート）を出す → 依頼者が番号で選ぶ → 組み合わせる。にじみ加工は「10 案 → 4 案を画面全体に → 2 番の強さ 3 段階 → 真ん中」と絞った。

## 4. 書き出しと確認

- プレビュー：文字の層を `--preview`（ultrafast、CRF20）で回す → 組み立てで 1280 幅・CRF23 veryfast にする。v7 は文字の層 4 分 11 秒＋組み立て約 2 分。
- スマホ用：プレビューを 854 幅・CRF31 にして 20MB 前後にする（SendUserFile は 30MB まで）。
- 本番：文字の層を `--segments-only`（CRF14 veryfast）で回す → 1920×816・CRF18 slow・AAC 320k。v7 は 7 分 46 秒、約 1.40GB。
- 確認すること：長さ・コマ数・解像度、注意書きの間が無音か、1〜5 秒ごとのコマ一覧、プレビューと本番の文字の計画の一致（text_log.json の言葉とフォント）、音量の推移（0.5 秒ごとの RMS）、LUFS とトゥルーピーク。
